# Accessory Working Weights

## Ratios for calculating a new accessory

Use these when a movement isn't in the table yet. Percentages are of the relevant main lift, for the given rep range.

| Movement type | % of main lift | Reference lift |
|---|---|---|
| Barbell Row (8–12) | 60–70% | Bench (205) |
| RDL / Stiff-Leg (8–10) | 55–65% | Conventional DL (305) |
| Good Morning (8–10) | 30–40% | Conventional DL |
| Overhead Press (3–5) | 55–65% | Bench |
| Front Squat (3–5) | 80–85% | Back/Box Squat |
| Close-Grip Bench (3–5) | 85–90% | Bench |
| Deficit Deadlift (3–5) | 85–90% | Conventional DL |

---

## Progression rule

If the top set of an accessory hits the **upper end of the rep range with 2+ reps still in the tank**, add weight next session:

- Barbell movements: **+10–20 lbs**
- EZ bar movements: **+5–10 lbs**
- Dumbbells: next size up, or add reps until the jump is manageable
