# DE Upper
*Upper body mass focus — speed work first, then high volume accessories*

## Speed Bench Press
9 x 3 @ ~60% of your ME weight (~65–70 lbs, bar + 10/side)
- Max speed off chest — weight is light, speed is the point
- 45–60s rest between sets
- Rotate grip: close / medium / wide (3 sets each)
- Add band tension if available

---

## Accessories — Upper Mass
*Pick one option per row — rotate for variation.*

| Exercise | Sets x Reps | Notes |
|---|---|---|
| DB Incline Press **or** Flat DB Press | 4 x 10–12 | 35 lb DBs — upper chest / overall chest thickness |
| Bent Over Rows **or** Lawnmowers (single-arm DB row) | 4 x 8–10 · 4 x 10–12 | Barbell back width / heavy 35 lb DB, brace hard |
| Arnold Press **or** Overhead Press | 4 x 10–12 | 35 lb DBs / barbell — full delt development |
| JM Press **or** Tricep Pushdowns (band) | 3–4 x 10–12 · 3 x 12–15 | EZ bar mass builder / volume tricep work |
| EZ Bar Skull Crushers **or** Close-Grip Push-ups | 3 x 10–12 | Superset with curls if pressed for time |
| EZ Bar Curls **or** DB Curls | 3 x 10–12 | Bicep mass |
| Hammer Curls **or** Cross-Body Hammer Curls | 3 x 12–15 | Arm thickness |
| Band Pull-Aparts **or** Face Pulls | 3 x 20 | Rear delt, shoulder health — don't skip |

**Rest:** 45–60s on speed sets, 60–90s on accessories
