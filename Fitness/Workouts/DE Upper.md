# DE Upper
*Upper body mass focus — speed work first, then high volume accessories*

## Speed Bench Press
9 x 3 @ ~60% of your ME weight (~65–70 lbs, bar + 10/side)
- Max speed off chest — weight is light, speed is the point
- 45–60s rest between sets
- Rotate grip: close / medium / wide (3 sets each)
- Add band tension if available

---

## Accessories — Upper Mass

| Exercise | Sets x Reps | Notes |
|---|---|---|
| DB Incline Press | 4 x 10–12 | 35 lb DBs — upper chest thickness |
| Bent Over Rows | 4 x 8–10 | Barbell — back width and thickness |
| Arnold Press | 4 x 10–12 | 35 lb DBs — full delt development |
| JM Press | 3–4 x 10–12 | EZ bar — best tricep mass builder in the program |
| EZ Bar Skull Crushers | 3 x 10–12 | Superset with curls if pressed for time |
| EZ Bar Curls | 3 x 10–12 | Bicep mass |
| Hammer Curls | 3 x 12–15 | Arm thickness |
| Band Pull-Aparts | 3 x 20 | Rear delt, shoulder health — don't skip |

**Rest:** 45–60s on speed sets, 60–90s on accessories
