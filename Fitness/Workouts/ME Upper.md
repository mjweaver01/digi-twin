# ME Upper

## Main Lift
**Pick one:** Flat Bench, Close-Grip Bench, Floor Press, EZ Bar Floor Press, or Incline Bench

**For mass, bias toward heavy 3s and 5s — not true singles.** Work up to a top 3–5RM most weeks; save true singles for when you actually want to test. Triples build size with less CNS drain.

Rotating the variation frequently is fine at your level, but hold a lift for ~2 weeks now and then so you can grind a real progression instead of always hitting a "fresh" PR. Don't repeat the same ME lift back to back within a week. Ramp slowly; if form breaks, drop weight.

## Accessories
*Pick one option per row — rotate for variation.*

*Priority: pull heavy first (back is the weak link), then press, then arms last.*

| Exercise | Sets x Reps | Notes |
|---|---|---|
| **Pull-ups / Chin-ups** (weighted or banded) | 4 x 6–12 | **Vertical pull for lat width — currently missing. Add every upper day.** |
| Barbell Rows **or** Pendlay / Chest-Supported Rows **or** Lawnmowers | 4 x 8–12 | Load the barbell heavy for back thickness; if using 35 lb DBs, go 15–20 to failure |
| JM Press **or** EZ Bar Skull Crushers | 3–4 x 8–10 · 3 x 10–12 | EZ bar tricep mass — bar to throat, elbows forward / elbows in, full stretch |
| DB Incline Press **or** Arnold Press | 3–4 x 12–20 | 35 lb DBs — chase reps to failure since weight is capped |
| Band Pull-Aparts **or** Face Pulls | 3–4 x 20 | Rear delt, shoulder health — don't skip |
| EZ Bar Curls **or** Hammer Curls | 2–3 x 10–15 | Pick one — arm volume is already plenty across the week |

**Rest:** 3–5 min on ME work, 60–90s on accessories
