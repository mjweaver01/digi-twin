# DE Lower
*Lower body speed + posterior chain, with upper body accessory for extra mass stimulus*

## Speed Box Squats
10–12 x 2 — **wave the bar weight on a 3-week pendulum + band tension**
- **Week 1 = 50%, Week 2 = 55%, Week 3 = 60%** of your ME box squat, then reset
- **Add band tension** (band over the bar, anchored under feet/rack) — accommodating resistance is the point of DE
- Reference: box squat ~235 → ~115 / 130 / 140 lbs bar weight across the 3 weeks, + band
- Sit back onto bench, pause, explode up
- 45–60s rest

## Speed Deadlifts
6–8 x 1 — same 3-week wave (**~50/55/60%**) + band tension if set up
- Reference: DL ~275 → ~135 / 150 / 165 lbs across the weeks
- Full reset each rep, explosive pull

## Lower Accessories
*Pick one option per row — rotate for variation.*

| Exercise | Sets x Reps | Notes |
|---|---|---|
| Good Mornings **or** RDLs | 3–4 x 8–10 | **Load the barbell — not "light."** Heavy hinge builds the thick posterior chain |
| **Banded Leg Curls or Nordic Curls** | 3 x 10–15 | **Direct hamstring work — currently missing. Add every DE Lower.** Band anchored, curl heel to glute |
| **Back Raises / Bench Back Extensions** **or** Banded Reverse Hyper | 3 x 12–20 | **Lower-back / reverse-hyper substitute — don't skip.** Face-down over bench, band around ankles |
| KB Swings **or** Hip Thrusts | 3 x 20 | 35 lb KB / glute-focused |
| Core | 3 x 10–15 | Hanging leg raises or weighted sit-ups — hit it every session |

## Upper Accessories (bulk focus)
*Pick one option per row — rotate for variation.*

| Exercise | Sets x Reps | Notes |
|---|---|---|
| **Pull-ups / Chin-ups** (weighted or banded) | 3–4 x 6–12 | Lat width — add on lower day too |
| Barbell Rows **or** Lawnmowers **or** DB Shrugs | 4 x 8–12 · 4 x 15–20 · 4 x 10 | Load the barbell heavy, take DBs to failure, or shrugs (35 lb DBs) for trap/upper-back thickness |
| EZ Bar Curls **or** Hammer Curls | 3 x 10–15 | One is plenty — arms are well-covered |
| Band Pull-Aparts / Face Pulls | 3 x 20 | Rear delt, shoulder health |

**Rest:** 45–60s on speed sets, 60–90s on accessories
