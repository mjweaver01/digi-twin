# Travel & Minimal Equipment

Reusable sessions for hotels, visits, and anywhere without the home rack. Pick the tier that matches what's actually available.

> **First principle: a few days off heavy loading is not a setback.** Strength doesn't meaningfully decay in under a week, and after a stretch of max-effort work a forced break functions as a deload. Zero sessions on a short trip is an acceptable outcome. Do not chase junk volume in a bad hotel gym.

> **Pack the light + medium bands.** They weigh almost nothing, fit in any bag, and are the difference between Tier 3 being useless and being genuinely productive.

---

## Tier 1 — Real gym (barbell + rack available)

Run a normal **DE day** at the current wave position. Never test a max on the road — unfamiliar bar, unfamiliar plates, no spotter.

| Exercise | Sets x Reps | Notes |
|---|---|---|
| Speed Bench **or** Speed Squat | 9 x 3 / 10–12 x 2 | Current wave % — see [[Fitness/Progress/Accessory Working Weights]] |
| Barbell Rows | 4 x 8–12 | 140 |
| Press accessory (DB incline / Arnold / OHP) | 4 x 10–12 | Whatever's available |
| Arms — two curl variations | 3 x 10–12 · 3 x 12–15 | |
| Band Pull-Aparts | 3 x 20 | |
| Toes-to-Bar | 3 x 10–15 | If there's a bar |

---

## Tier 2 — Dumbbells + bench

Most hotel gyms. Chase reps — the DBs will be lighter than you want, so take sets close to failure.

| Exercise | Sets x Reps | Notes |
|---|---|---|
| DB Flat **or** Incline Press | 4 x 12–20 | Close to failure — weight will be capped |
| Single-Arm DB Row (Lawnmowers) | 4 x 12–15/side | Your preferred pull |
| DB Goblet Squat **or** DB RDL | 3–4 x 12–15 | Slow eccentric to make light weight count |
| Arnold Press **or** DB OHP | 3–4 x 10–12 | |
| DB Curls | 3 x 10–12 | |
| Hammer Curls | 3 x 12–15 | |
| Band Pull-Aparts | 3 x 20 | |
| Toes-to-Bar **or** Hanging Leg Raise | 3 x 10–15 | If there's a bar |

## Tier 3 — Hotel room (bodyweight + bands)

No equipment beyond what you packed. Keep rest short, chase the pump, don't pretend it's a strength session.

| Exercise | Sets x Reps | Notes |
|---|---|---|
| Push-ups (feet elevated for difficulty) | 4 x 15–25 | Slow eccentric, full ROM |
| Band Chest Press (anchor behind, door or post) | 4 x 15 | |
| Band Rows (anchor at waist height) | 4 x 15–20 | Squeeze at the back |
| Band Overhead Press | 3 x 12–15 | |
| Bulgarian-free single-leg work: Reverse Lunges | 3 x 12–15/leg | ⛔ Not Bulgarian split squats |
| Band Curls | 3 x 15–20 | |
| Band Tricep Pushdowns | 3 x 15–20 | |
| Band Pull-Aparts | 3 x 20 | Shoulder health — always |
| Planks / Sit-ups | 3 sets | No bar for toes-to-bar |

## Returning home

Resume the normal rotation at the wave position you left off — **do not restart the wave** and do not try to "make up" missed sessions. If you were away 4+ days, the first session back should be a DE day rather than a max attempt: the break blunts technical sharpness before it touches strength, and a max on a rusty groove is how form breaks down.

## ⛔ Do not program
Bulgarian split squats · banded leg curls · Nordic curls · slider curls · back raises · farmer's & suitcase carries · preacher curls · hanging leg raises (when toes-to-bar is possible) — Mike dislikes these.
